# Using `/review` for Pam playtests

1. Play Stump Mom in the same browser.
2. Open `/review`.
3. Expand **Pam / Mom Mode**.
4. Expand a game to see the full ordered question and answer trace.
5. Use **Export Pam JSON** when a playtest needs to be shared or analysed outside the browser.

For each question the log includes source, gain, known coverage, semantic coverage, confidence, and the leading candidates at that point in the game.
